DEMO — transição de imagem por scroll

1. Abrir index.html num browser.
2. Fazer scroll para controlar a transição.
3. A imagem começa focada, entra num blur forte, mantém-se desfocada durante quase todo o percurso e recupera foco nos últimos 10%.
4. A imagem verde faz crossfade gradual para a imagem de outono/neve.
5. O widget lateral mostra a percentagem de progresso.

Para publicar: enviar a pasta inteira para qualquer alojamento estático (Netlify, Vercel, GitHub Pages, etc.).
